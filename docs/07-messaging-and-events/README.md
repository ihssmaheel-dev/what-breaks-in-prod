# Category 07: Messaging and Events

Decoupled asynchronous communication, streaming, backpressure, and guaranteed event processing.

## Why this matters in production
Synchronous HTTP chains between microservices create cascading outages when one service slows down. Event-driven architectures isolate failures, allow asynchronous processing, and smooth out traffic spikes, but introduce dead letter queues and ordering complexities.
