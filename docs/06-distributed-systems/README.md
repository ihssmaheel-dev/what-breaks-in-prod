# Category 06: Distributed Systems

Consensus, replication, partitioning, and coping with network failures across multiple servers.

## Why this matters in production
When state spans more than one machine, the network will partition, clocks will drift, and nodes will crash mid-transaction. Understanding CAP, consensus, and sagas protects your system from split-brain scenarios and data loss.
