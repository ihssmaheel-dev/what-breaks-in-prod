# Category 09: Networking and Real-Time

Protocols, low-level transport mechanisms, persistent bidirectional connections, and streaming RPCs.

## Why this matters in production
Modern real-time applications cannot rely on naive HTTP polling without exhausting server sockets and bandwidth. Knowing when to choose WebSockets vs SSE vs gRPC, and understanding DNS and transport layers, prevents connection exhaustion under heavy concurrent user load.
