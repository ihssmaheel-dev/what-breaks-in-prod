# Category 04: Databases

Data modeling, transactions, isolation levels, zero-downtime migrations, and query tuning for production storage engines.

## Why this matters in production
Code is easy to roll back, but corrupted or locked database tables cause lasting damage. Knowing how locks work, how indexes function under write pressure, and how to execute schema migrations without taking downtime separates junior engineers from seniors.
